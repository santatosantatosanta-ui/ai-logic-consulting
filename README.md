# AI-Logic Consulting LP

名刺からの閲覧を想定した、ショーリール形式の静的ランディングページです。ビルド工程は不要で、そのまま GitHub Pages に公開できます。

## 公開前の確認

問い合わせボタンはGmailのメール作成画面へ移動する設定です。クリックして宛先・件名・本文テンプレート入りの作成画面が開くか、公開前に一度確認してください。

GSAPモーションタイポグラフィは、cdnjsのGSAP 3.15.0をSRI付きで読み込んでいます。インターネット接続のない環境では通常表示になり、GitHub Pages上では動作します。

## GitHub Pages で公開する方法

1. この `ai-logic-consulting-lp` フォルダの内容を GitHub リポジトリのルートへ置きます。
2. GitHub の **Settings → Pages** を開きます。
3. **Build and deployment** で `Deploy from a branch` を選択し、公開するブランチと `/ (root)` を指定します。
4. 保存後に表示されるURLを名刺へ記載します。

`index.html` をローカルでブラウザに開くだけでも、公開前の表示確認ができます。
